# Azure AI Foundry Overview

Azure AI Foundry is a platform for building and managing AI applications, models, and evaluation workflows in Azure. For a prototype, it is useful as the control plane around model deployments and related AI services.

A practical prototype does not need to use every Foundry feature. For a first RAG demo, the most important requirement is a deployed chat model and a deployed embedding model that the backend can call reliably.

Foundry becomes more valuable as the system matures. Teams can add evaluation, prompt iteration, governance, and broader lifecycle tooling after the basic RAG flow is working.
